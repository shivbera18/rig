Why rig

Built for long runs, not one-shots.

Persistent sessions

Every answer saves to ~/.rig/sessions/. Resume, fork, rewind, retry, compact. The thread outlives the terminal.

45 slash commands

Status, usage, context, transcript, plan mode, goals, steering notes, task queue. Tab completes, fuzzy match forgives typos.

Multi-account auth pool

Round-robin credentials with 401/403 fallback. auth status, auth refresh, auth use keep every account healthy.

Isolated subagents

task spawns agents in detached git worktrees and merges their diffs back as patches. Your tree stays clean.

Model roles

@smol for mechanical edits, @default for deep work, @vision for images. One flag switches the chain.

CI-friendly headless

exec --format json and --format stream-json pipe structured results into scripts, with --output and --quiet.

How it runs

Prompt in. Patch out.

One pipeline from keystroke to merged diff. Every stage streams live in the session.

  1. 01

    Pool picks a credential

    Round-robin across stored accounts, refreshes expiring tokens, falls over on 401/403.

  2. 02

    Dispatch streams the model

    OpenAI completions, responses, or Anthropic messages. Text arrives token by token.

  3. 03

    Turn loop runs tools

    read write edit bash web_search task, parallel by default.

  4. 04

    Subagents merge patches

    Detached worktrees, strict output schemas, git apply back into your tree.

  5. 05

    Thread persists

    Resume, fork, rewind, compact. rig exec --continue picks up anywhere.

Sessions that outlive the terminal

Close the laptop. Keep the thread.

$ rig exec "again" --continue

$ rig sessions list
* mujx0kv8  stub/m  16 msgs

  • Resume the most recent thread or fork any saved one by id.
  • Compact long threads into a summary plus the last exchanges.
  • Export Markdown or copy the last answer to the clipboard.
  • Headless handoff: --format json pipes results into CI.
