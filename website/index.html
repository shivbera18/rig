Why rig

Built for long runs, not one-shots.

Persistent sessions

Every answer saves to ~/.rig/sessions/. Resume, fork, rewind, retry, compact. The thread outlives the terminal.

45 slash commands

Status, usage, context, transcript, plan mode, goals, steering notes, task queue. Tab completes, fuzzy match forgives typos.

Multi-account auth pool

Round-robin credentials with 401/403 fallback. auth status, auth refresh, auth use keep every account healthy.

Isolated subagents

task spawns agents in detached git worktrees and merges their diffs back as patches. Your tree stays clean.

Model roles

@smol for mechanical edits, @default for deep work, @vision for images. One flag switches the chain.

CI-friendly headless

exec --format json and --format stream-json pipe structured results into scripts, with --output and --quiet.
